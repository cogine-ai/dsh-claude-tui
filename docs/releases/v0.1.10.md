# v0.1.10 — DSH 0.2.2-rc.1, security and terminal usability

[简体中文](./v0.1.10.zh-CN.md)

Requires Node.js **24.9+**. Bundles DSH `0.2.2-rc.1` at `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`. External DSH must satisfy `>=0.2.2-rc.1 <0.2.3` and pass isolated behavior and dependency probes.

## Changes

- Uses explicit Native/PTC executors; `code` remains a PTC alias. Launcher and direct-profile startup reject unsupported `both`.
- Persists Agent model selection before the first request; resume keeps the recorded route unless explicitly overridden.
- Updates Cordis/Loader activation, Session projections and subagent lifecycle. Mirrors 2,373 original upstream documentation files, excluded from npm.
- Repairs MCP client/core `2.3.0`, undici `8.12.2` and Zod `4.6.6`. The portable artifact carries all 324 DSH packages, including 60 manifest-only repairs, preserving original code and licenses; required external dependencies are pinned.
- Scrolls command, file and Session lists with the selection. Short model, approval and question dialogs retain choices and controls. At 32 columns, command names take priority over descriptions.
- Adds clear selection arrows, including file and multi-select menus without color; aligns the slash menu with independent Claude Code `2.1.311` captures.
- Collapses the welcome panel after the first durable user message, recovering seven rows while preserving the draft and conversation.
- Updates the real macOS clipboard regression to the current image-capable `deepseek-flash` route. Arbitrary model routes do not gain image support.

## Install

```sh
npx --yes --legacy-peer-deps dsh-claude-tui@0.1.10
# Persistent commands:
npm install --global --legacy-peer-deps dsh-claude-tui@0.1.10
dshtui
```

Ordinary npm peer resolution is also qualified. The optional flag avoids resolving unused Web UI peers; installed dependency trees are checked separately. Real requests need your DSH provider credentials (`/provider`). Use `/model` for model/effort and `dshtui --resume` to restore a Session.

Use separate Homes for cross-version testing. V4 format identity does not promise downgrade compatibility; supported predecessor migrations preserve originals.

## Verification and limits

The macOS arm64 / Node `24.22.1` full gate passed **273/273**, including ordinary npm installation, strict dependency trees, production audit, MCP/undici/Zod regressions, PTC, native subagents, shutdown/resume and Session migrations. The real macOS system-clipboard test passed through paste, Files and Messages against a local server; the original clipboard was restored. This run reused the npm cache.

Node `24.9.0` passed **99/99** focused application, Session-picker, clipboard and model-selection checks. Real isolated DSH PTYs cover 14 states, including streaming, history, file mentions and small windows. Four of nine new Claude Code `2.1.311` frames are automated anchors; the original `2.1.227` corpus is preserved. See [before/after evidence](../ux-validation-0.1.10.md).

These results use local model/Files/MCP servers. They do not qualify production DeepSeek requests, OAuth/SSO, native IME composition, light themes or Windows ConPTY. DSH permission semantics remain authoritative; Claude's newer auto-mode approval choices are not advertised as supported.

Publication identity and artifacts are recorded in the [GitHub Release](https://github.com/cogine-ai/dsh-claude-tui/releases/tag/v0.1.10). See the [DSH adaptation record](../harness-0.2.2-rc.1-adaptation.md) for earlier checks.
