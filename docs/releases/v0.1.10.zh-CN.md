# v0.1.10 — DSH 0.2.2-rc.1、安全与终端体验

[English](./v0.1.10.md)

需要 Node.js **24.9+**。内置 DSH `0.2.2-rc.1`，固定提交 `66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`。外部 DSH 须满足 `>=0.2.2-rc.1 <0.2.3` 并通过隔离行为及依赖探针。

## 变化

- 使用独立 Native/PTC 执行器；`code` 保留为 PTC 别名。启动器和直接启动 profile 都拒绝不再支持的 `both`。
- 首次请求前即可持久化 Agent 模型选择；恢复会话保留路由，仅在显式指定时覆盖。
- 更新 Cordis/Loader 激活、Session 投影及子代理生命周期；同步 2,373 份上游文档原文件，镜像不进入 npm 安装包。
- 修复 MCP client/core `2.3.0`、undici `8.12.2`、Zod `4.6.6`。可移植制品携带全部 324 个 DSH 包，其中 60 个仅修复依赖清单，保留原代码和许可证；必需的外部依赖也被固定。
- 命令、文件和会话列表跟随选中项滚动。短窗口的模型、审批和问答弹窗保留选项与操作；32 列命令菜单优先完整显示命令名。
- 增加明确的选中箭头，无颜色文件及多选菜单也可辨识；命令菜单对齐独立采集的 Claude Code `2.1.311` 参考。
- 首个持久化用户消息到达后收起欢迎面板，释放七行，并保留草稿与对话。
- 真实 macOS 图片剪贴板回归改用当前支持图片的 `deepseek-flash`；不代表为任意路由新增图片能力。

## 安装

```sh
npx --yes --legacy-peer-deps dsh-claude-tui@0.1.10
# 持久安装：
npm install --global --legacy-peer-deps dsh-claude-tui@0.1.10
dshtui
```

普通 npm peer 求解也已验证。可选参数用于避免求解未使用的 Web UI peers，安装后的完整依赖树另行检查。真实请求需要所选 DSH Provider 的凭据（`/provider`）；用 `/model` 选择模型及 effort，`dshtui --resume` 恢复会话。

跨版本测试使用独立 Home。V4 格式相同不代表可以降级；受支持的旧版本迁移保留原件。

## 验证及限制

macOS arm64 / Node `24.22.1` 完整检查 **273/273 通过**，包括普通 npm 安装、严格依赖树、生产审计、MCP/undici/Zod 回归、PTC、原生子代理、退出/恢复和会话迁移。真实 macOS 系统剪贴板测试通过图片粘贴、Files 和 Messages 本地服务链路，原剪贴板已恢复。该次检查复用了 npm 缓存。

Node `24.9.0` 的应用、会话选择器、剪贴板及模型选择检查 **99/99 通过**。隔离真实 DSH PTY 覆盖 14 个状态，包括流式回复、历史、文件提示及小窗口。新增 9 帧 Claude Code `2.1.311` 参考，其中 4 帧用于自动比较；原 `2.1.227` 参考保留。详见[前后对比](../ux-validation-0.1.10.md)。

上述结果使用本地模型、Files 和 MCP 服务，不构成真实 DeepSeek 线上请求、OAuth/SSO、原生输入法组合态、浅色主题或 Windows ConPTY 验收。DSH 权限语义保持真实，不宣称支持 Claude 新增的自动权限审批选项。

发布身份和制品见 [GitHub Release](https://github.com/cogine-ai/dsh-claude-tui/releases/tag/v0.1.10)。之前的检查见 [DSH 适配记录](../harness-0.2.2-rc.1-adaptation.md)。
