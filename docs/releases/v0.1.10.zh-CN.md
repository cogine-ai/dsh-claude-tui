# v0.1.10 — 适配 DSH 0.2.2-rc.1（未发布）

[English](./v0.1.10.md)

包内 DSH 从 `0.2.1-rc.2` 升到 `0.2.2-rc.1`，固定提交
`66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`。Node.js 最低版本升为 **24.9**。
外部 DSH 必须满足 `>=0.2.2-rc.1 <0.2.3` 并通过隔离行为探针。

- Native/PTC 改用独立执行器插件，保留 TUI 环境变量入口。
- 模型选择通过上游 Agent model API 持久化，尚未使用的选择也能恢复；仅显式指定时覆盖。
- 更新 Cordis/Loader 服务激活与依赖组合。
- 同步精确运行时版本的 2,373 份官方文档原文件。

从工作区执行 `corepack pnpm install --frozen-lockfile`、`corepack pnpm build`，
再以 `node lib/cli.js` 运行。测试请使用独立 `DSH_HOME`；V4 格式相同不代表支持降级。

实际验证及覆盖范围见[适配记录](../harness-0.2.2-rc.1-adaptation.md)。
本次变更尚未发布到 npm 或 GitHub Releases。

安全修复：MCP client/core `2.3.0`、undici `8.12.2`、Zod `4.6.6`；60 个 DSH 包仅修改依赖清单，并随完整的 324 个 DSH 包一起携带。使用 `corepack pnpm run pack:artifact` 构建可移植的本地安装包。

验证：Node `24.22.1` 完整门禁 249 项通过、1 项可选剪贴板测试跳过；Node `24.9.0` 普通 npm 安装包门禁 20 项通过、1 项跳过。工作区及安装包生产依赖审计均为零漏洞，严格依赖树检查通过；原版对照能够复现已修复的安全问题。覆盖限制详见适配记录。本次未发布。
