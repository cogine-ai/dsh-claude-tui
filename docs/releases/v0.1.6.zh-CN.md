# v0.1.6 — DSH 0.1.2-rc.1 与官方文档

[English](./v0.1.6.md)

本版本将包内 DeepSeek Harness 从 `0.1.1-rc.2` 升级到 `0.1.2-rc.1`，并在仓库中维护与运行时版本一致的官方文档镜像。

## 变化

- 会话回放、结构化提问、提供方设置与首 token 计时适配新版 Harness API。保留已有图片输入、附件持久化、计划模式、审批与会话恢复。
- PTC 工具模式采用新值 `ptc`，继续接受 `DSH_TOOLS_MODE=code` 别名；`native` 与 `both` 仍然可用。
- 外部 DSH 运行时须满足 `>=0.1.2-rc.1 <0.1.3` 并通过独立 Home 中的行为探针；包内运行时精确固定为 `0.1.2-rc.1`。
- 显式包含 npm 冷安装所需的运行时 peer，保留 Sharp `0.35.3`。标准 npm peer 求解和 `--legacy-peer-deps` 两条路径都有安装包验证。
- 同步 1,332 个官方原文件，包含 882 个 Markdown 文件与 433 篇中文文档。[文档入口](../upstream/dsh/README.md) 提供导航、来源记录、许可证及同步和校验命令。CI 校验快照，镜像不进入 npm 安装包。

## 安装

本版本在 npm 上可用后：

```bash
npx --yes --legacy-peer-deps dsh-claude-tui@0.1.6
```

如需常驻命令：

```bash
npm install --global --legacy-peer-deps dsh-claude-tui@0.1.6
dshtui
```

需要 Node.js `22.19+` 或 `24+`。不带 `--legacy-peer-deps` 的标准 npm 安装也可用，但冷安装的 peer 求解可能需要数分钟。短命令 `dshtui` 与正式命令 `dsh-claude-tui` 使用同一个启动器。

## 升级注意事项与验证范围

上游移除了可选的 SQLite **Session 持久化**后端。如果使用过该后端，请先用旧版 Harness 导出会话。SQLite 查询和索引存储是另一项服务。跨版本测试请使用独立 Home；本 TUI 不提供 SQLite 导出器或降级迁移。

已验证的平台范围仍为 macOS arm64 与 Linux x64；Windows/ConPTY 尚未取得发布资格。确定性的安装包测试通过本地 Provider mock 验证聊天、工具及会话恢复，不代表真实生产 Provider 的验证结果。真实系统剪贴板与 Files API 图片流程是独立的 opt-in gate，本发布候选尚未运行该项。

详见[适配记录](../harness-0.1.2-rc.1-adaptation.md)及[上游官方发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.2-rc.1)。上游 Web 文档不代表本 TUI 已提供相同界面。
