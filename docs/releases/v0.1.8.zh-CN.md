# v0.1.8 — DSH rc.2 依赖安全修复

[English](./v0.1.8.md)

`0.1.8` 修复 TUI `0.1.7` 已记录的依赖问题：五份公告涉及 **14 个受影响生产包条目，其中 6 个 high、8 个 moderate**。保持 DeepSeek Harness `0.2.0-rc.2` 及其源码、Claude Code `2.1.227` 交互目标与现有 Node.js 支持契约。

## 变化

- 更新 Sharp `0.35.3` → `0.35.5`、MCP client/core `2.0.0` → `2.2.0`、fast-uri `3.1.7` → `3.1.8`，以及 libreoffice-kit 实际消费的 fflate `0.8.2` → `0.8.3`。
- MCP 与 fflate 的上游精确 pin 采用可复现依赖归档修复，仅修改所属包的 `package.json` 依赖声明。保留包名、版本、上游源码字节、文件模式与许可证。这些归档由本项目维护，不是上游新发布版本。
- 两份公开 HTTPS 归档固定到包含归档的完整 Git 提交，两份锁文件及[来源记录](https://github.com/cogine-ai/dsh-claude-tui/blob/0e0e57954e3502234fbd8a835b6fdaff235de3ad/vendor/security/provenance.json)保存完整性。merge commit 保留归档提交的祖先关系与依赖来源。普通 npm 消费者无需配置 override 或运行安装补丁；首次安装还需访问 GitHub raw 内容。
- 在声明允许范围内，将工作区、可选及开发依赖收敛到修复版。保留工作区原有 GenAI MCP 桥接能力，使用 SDK v1 `1.31.0` 并新增本地 stdio 回归；发布生产依赖图仍不包含 SDK v1。
- 新增实际依赖消费路径回归，覆盖原生 PNG/SVG 转换、Office ZIP 正常读写与硬超时内拒绝异常 ZIP64、AJV URI 规范化及 DSH MCP stdio/HTTP 桥接。继续要求已有 CLI、PTC、Session、迁移与终端检查通过。

## 安装

精确选择本版本：

```bash
npx --yes dsh-claude-tui@0.1.8
```

需要长期使用时：

```bash
npm install --global dsh-claude-tui@0.1.8
dshtui
```

需要 Node.js **22.x 的 22.19+，或 24.2+**（`^22.19.0 || >=24.2.0`）。`dshtui` 与 `dsh-claude-tui` 使用同一启动器。DSH 保持 `0.2.0-rc.2`；外部运行时仍须满足 `>=0.2.0-rc.2 <0.2.1` 并通过隔离行为探针。外部 DSH 安装有独立依赖图，本次修复针对包内依赖图。

## 升级与验证

本次保留 DSH V4 Session 格式与现有 managed Home 行为。受支持的旧格式迁移保留原件字节。跨版本测试继续使用独立 Home，避免多个运行时并发共享同一 Home。

2026-10-11 在安全修复候选提交 [4d604c9](https://github.com/cogine-ai/dsh-claude-tui/commit/4d604c9)、升版 `0.1.8` 前记录的验证：

- 完整工作区审计：807 个依赖条目 **0 份公告**，包含保留的可选 SDK v1 分支。
- macOS arm64、Node `24.16.0` 全量检查：16 个文件 **184 项通过 / 1 项跳过**，类型检查、构建及 1,803 个官方 DSH 文档文件均验证通过。
- Node `22.23.3`、npm `10.9.9`，全新缓存普通 npm 安装、无消费方 override：**生产审计 0**，278 个已安装 DSH 包全部保持 `0.2.0-rc.2`。普通 npm bundle gate 为 **14 项通过 / 1 项跳过**；实际原生库版本为 heif `1.23.5`、rsvg `2.63.2`、vips `8.18.7`。
