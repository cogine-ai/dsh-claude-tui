# v0.1.9 — DSH 0.2.1-rc.2 适配

[English](./v0.1.9.md)

`0.1.9` 将 DeepSeek Harness 从 `0.2.0-rc.2` 升至 `0.2.1-rc.2`，对应提交
`687f282e8625c6b8d11ff58211a90524be2e4317`。外部运行时须满足
`>=0.2.1-rc.2 <0.2.2` 并通过隔离行为探针，Node 要求保持
`^22.19.0 || >=24.2.0`。

## 变化

- 工具模式支持 `native` 和 `ptc`，`code` 仍是 PTC 别名；`both` 会在发现运行时、
  执行探针或修改 DSH Home 前明确报错。
- 移除 runtime invariant companions 与独立 in-process 子代理 driver，采用托管
  activation 与发给父代理的完成通知；Started 回执与最终答案分别显示。
- 删除不再支持的 `{{cwd}}` prompt 变量，文件补全跟随持久化当前目录，保留
  Session 原始项目身份。
- 保留 DSH 管理的模型选择、凭据、已解析设置、实时回复、V4 回放、附件、审批与
  问题；本交互 profile 中已保存的 API Key 现优先于环境变量。
- 使用已内置 client `2.2.0` 的官方 MCP 包，替代旧 repack。LibreOffice 上游仍固定
  fflate `0.8.2`，因此保留选择 `0.8.3` 的现有 repack。
- 从精确目标提交同步 2,083 份官方文档原文件，镜像继续不进入 npm 安装包。

## 安装

```bash
npx --yes --legacy-peer-deps dsh-claude-tui@0.1.9
```

需要长期使用时：

```bash
npm install --global --legacy-peer-deps dsh-claude-tui@0.1.9
dshtui
```

在当前 checkout 执行：

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm build
DSH_HOME=/tmp/dsh-claude-tui-0.2.1-rc.2 DSH_CLAUDE_TUI_RUNTIME=bundled node lib/cli.js
```

跨版本测试使用独立 Home。Session 格式保持 V4，但这不代表旧运行时可以降级读取
新增事件或 plugin 记录。受支持的历史格式迁移继续保留原文件。
