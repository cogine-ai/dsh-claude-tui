# v0.1.9 — DSH 0.2.1-rc.2 adaptation

[简体中文](./v0.1.9.zh-CN.md)

Version `0.1.9` upgrades DeepSeek Harness from `0.2.0-rc.2` to `0.2.1-rc.2` at
`687f282e8625c6b8d11ff58211a90524be2e4317`. External runtimes require
`>=0.2.1-rc.2 <0.2.2` and an isolated behavioral probe. Node remains
`^22.19.0 || >=24.2.0`.

## Changes

- Accepts `native` and `ptc` tool modes. `code` remains a PTC alias; `both`
  now fails before runtime discovery, probes, or DSH Home changes.
- Removes runtime invariant companions and the standalone in-process subagent
  driver. Subagents follow managed activations and parent completion notices;
  Started receipts remain distinct from final answers.
- Removes the unsupported `{{cwd}}` prompt variable. File mentions follow the
  persisted current directory while Session project identity remains unchanged.
- Keeps DSH-owned model selection, credentials, resolved settings, live replies,
  V4 replay, attachments, approvals, and questions. Saved API keys now precede
  environment fallbacks in this interactive profile.
- Uses the official MCP owner package with client `2.2.0`, replacing its old
  repack. Retains the LibreOffice repack because upstream still pins fflate
  `0.8.2`; the repack selects `0.8.3`.
- Synchronizes 2,083 official documentation files from the exact target commit.
  The mirror remains outside the npm package.

## Install

```bash
npx --yes --legacy-peer-deps dsh-claude-tui@0.1.9
```

For a persistent command:

```bash
npm install --global --legacy-peer-deps dsh-claude-tui@0.1.9
dshtui
```

From this checkout:

```bash
corepack pnpm install --frozen-lockfile
corepack pnpm build
DSH_HOME=/tmp/dsh-claude-tui-0.2.1-rc.2 DSH_CLAUDE_TUI_RUNTIME=bundled node lib/cli.js
```

Use a separate Home for cross-version testing. Session format remains V4, but
that does not establish downgrade compatibility for new event or plugin records.
Supported predecessor migrations preserve the original files.
